# Oasis 2025 portfolio restoration

Starting main commit: `1e6e4fdc6796835048cd3192ef7302e700425d24`.

The original Japanese illustrated design, drawing entrance, ink reveal, doors, scroll scenes, artwork, fonts and routes are preserved. A subtle persistent label identifies the portfolio archive and registration demo. The original brochure, gallery, contact records, sponsors and media partner records remain local historical repository content.

Event fixtures preserve twenty real names/categories extracted from the checked-in `src/assets/Oasis_25_Brochure.pdf`; unavailable descriptions, schedules and clubs are explicitly identified as representative demo details. Photography has an explicitly representative demo event. The original category fan, event carousel and registration selection screens consume these local records. Registration begins with a fictional sample identity (`demo@example.invalid`), validates fields locally in the original form, then confirms selected events in memory. Google OAuth, cookies, analytics, POST redirects, remote API calls, browser storage, real submission and payment flows are removed. The registration instruction modal also explains these limits.

React/React DOM 19.3.0 and Vite 7.3.6 produce static `dist`. Route components use lazy chunks. Home drawing progress is independent of remote or missing media; its original drawing animation remains. Door transitions navigate as soon as closing completes, opening without waiting for images/videos. Original media load progressively. Failed/cached event images no longer deadlock their placeholder. Brochure preview is lazy native PDF; the original YouTube player initializes when its container enters view, preserving its original controls.

Large illustrations and photographs are preprocessed to WebP at appropriate dimensions. Raster payloads inside SVGs are recompressed while their surrounding SVG geometry remains. The optimized set falls from 203,812,768 to 21,159,381 bytes. Pages blockers treeOg.png (29.7MB) and music.svg (31.36MB) are resolved. Unreferenced large public backups are removed from deployment, and remain recoverable in Git history. Public assets fall from approximately 231MB to 36MB; dist falls from about 259MB to 59MB. Original font files are subset to WOFF2 using Latin, extended Latin, punctuation and every source-text glyph; original families and actual weight declarations remain. Missing declarations for the checked-in Ibarra regular and Averia fonts are supplied. Font and asset byte records are in `evidence/`.

Wrangler 4.145.0 is pinned for Pages project `dvm-portfolio-oasis-2025`. The deploy command sets account ID via environment, because account_id is unsupported in Pages Wrangler configuration. Compatibility date is 2026-09-30 (current Cloudflare UTC date). Native Pages SPA fallback is used without a redirect loop. Canonical/social URLs use https://oasis2025.bits-oasis.org; custom domain setup is deferred. No Worker is required. CSP permits local scripts and the original YouTube iframe API, contains no unsafe-eval or inline-script permission, and stays below the 2KB header line cap. Inline animation styles are permitted. Security headers, `.wrangler/` ignore and validation-only GitHub CI replace obsolete SSH deployment.

Validation: locked `npm ci --legacy-peer-deps`, TypeScript compilation, Vite production build, static checks for Pages file limits/CSP/canonical/fonts and absence of live backend/auth/storage, plus full production/development `npm audit` with zero vulnerabilities. All deployed files are below 25MiB. Logs and machine reports are checked in under `evidence/`. Source review found no form POST, unsafe HTML injection or credentials. Browser checks and publishing are owned by the root agent. Mobile and extensive performance testing were explicitly waived by the user.

Limits: the main illustrated homepage bundle remains comparatively large; its drawing/animation code and scroll scenes are preserved. Original public social/contact links retain historical destinations. External video availability and browser-native PDF support are outside this static archive's control. The demonstration never creates a registration, account, email or payment.
